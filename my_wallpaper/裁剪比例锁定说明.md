# 图片裁剪比例锁定功能说明

## 功能概述

imageCropper 组件现已支持严格按比例裁剪，确保裁剪结果符合传入的 `targetWidth:targetHeight` 比例要求。

## 核心计算规则

### 最大裁剪范围计算（`calculateMaxCropSize` 函数）

根据原图尺寸和目标比例，自动计算原图中符合比例的最大可裁剪区域：

#### 规则 1：宽 > 高
- **以高度为基准**
- 最大裁剪高度 = 原图高度
- 最大裁剪宽度 = 原图高度 × (targetWidth / targetHeight)
- 确保宽度 ≤ 原图宽度

#### 规则 2：高 > 宽
- **以宽度为基准**
- 最大裁剪宽度 = 原图宽度
- 最大裁剪高度 = 原图宽度 × (targetHeight / targetWidth)
- 确保高度 ≤ 原图高度

#### 规则 3：宽 = 高（正方形）
- 最大裁剪范围 = 原图尺寸

## 实际案例：338×796 原图 + 1:1 目标比例

### 计算过程

1. **判断原图特征**
   - 原图宽度 W = 338px
   - 原图高度 H = 796px
   - H > W，触发「高 > 宽」规则

2. **计算最大裁剪范围**
   - 最大裁剪宽度 = 338px（原图宽度）
   - 最大裁剪高度 = 338 × (1/1) = 338px
   - 最终最大裁剪范围：**338×338**（正方形）

3. **组件行为**
   - 裁剪框严格锁定为 1:1 比例
   - 用户可拖动图片调整显示区域
   - 裁剪框固定在预览区中心
   - 最终裁剪结果不超过 338×338 范围
   - 裁剪区域始终在原图边界内

## 其他比例示例

### 示例 1：1920×1080 原图 + 9:16 目标比例
- W (1920) > H (1080)，触发「宽 > 高」规则
- 最大裁剪高度 = 1080px
- 最大裁剪宽度 = 1080 × (9/16) = 607.5px
- 最终最大裁剪范围：**607.5×1080**

### 示例 2：800×600 原图 + 16:9 目标比例
- W (800) > H (600)，触发「宽 > 高」规则
- 最大裁剪高度 = 600px
- 最大裁剪宽度 = 600 × (16/9) = 1066.67px
- 但 1066.67 > 800（原图宽度），所以调整为：
- 最大裁剪宽度 = 800px
- 最大裁剪高度 = 800 × (9/16) = 450px
- 最终最大裁剪范围：**800×450**

### 示例 3：500×500 原图 + 任意比例
- W = H，正方形原图
- 最大裁剪范围 = **500×500**
- 实际裁剪时会按目标比例在这个范围内裁剪

## 技术实现要点

### 1. 比例严格锁定
- 裁剪框尺寸始终保持 `targetWidth:targetHeight` 比例
- 在 `handleConfirm` 中进行二次校验，防止浮点误差

### 2. 边界保护
- 裁剪区域自动限制在原图边界内
- 使用 `Math.max` 和 `Math.min` 确保坐标合法

### 3. 显示优化
- 图片显示尺寸根据最大裁剪范围自动计算
- 确保用户可以拖动图片调整显示区域
- 裁剪框固定居中，提供清晰的视觉参考

## 使用方式

```vue
<imageCropper
  :imageUrl="imageUrl"
  :imageInfo="{ width: 338, height: 796 }"
  :targetWidth="1"
  :targetHeight="1"
  @confirm="handleCropConfirm"
  @close="showCropper = false"
/>
```

## 返回数据格式

```javascript
{
  x: 0,        // 裁剪区域左上角 X 坐标（原图像素）
  y: 229,      // 裁剪区域左上角 Y 坐标（原图像素）
  width: 338,  // 裁剪宽度（原图像素）
  height: 338  // 裁剪高度（原图像素）
}
```

裁剪结果严格保持 `targetWidth:targetHeight` 比例，可直接用于后端裁剪处理。
