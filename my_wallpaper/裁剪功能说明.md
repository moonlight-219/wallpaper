# 创作页面裁剪功能说明

## 功能概述
创作页面采用类似手机原生壁纸设置的裁剪交互方式，裁剪框固定在中心，用户通过拖动图片来调整显示区域。

## 核心功能

### 1. 三种上传类型
- **手机壁纸**：建议尺寸 1080×2400，大小不超过 5MB
- **平板壁纸**：建议尺寸 2048×2732，大小不超过 8MB  
- **头像分享**：建议尺寸 500×500，大小不超过 2MB

### 2. 智能校验
- 上传图片时自动校验尺寸和文件大小
- 尺寸允许 10% 误差范围，超出则提示裁剪
- 文件大小超限直接拒绝上传

### 3. 裁剪交互（核心特性）

#### 交互方式
- **裁剪框固定**：裁剪框始终居中显示，尺寸和比例锁定
- **智能尺寸**：以图片宽高中较小的一边作为基准，形成四边形裁剪框
- **拖动图片**：用户拖动图片来调整显示区域（类似手机原生壁纸设置）
- **比例锁定**：裁剪框比例自动匹配当前Tab的标准尺寸
- **无法调整框体**：裁剪框大小和比例不可修改，四个角固定不可拖拽

#### 裁剪流程
1. 上传图片尺寸不符时，弹出确认对话框
2. 点击"去裁剪"打开裁剪界面
3. 裁剪界面显示：
   - 固定在中心的裁剪框（白色边框）
   - 可拖动的图片（自动缩放以覆盖裁剪框）
   - 四个角的装饰性标记（主题色）
   - 九宫格辅助线（帮助构图）
   - 底部尺寸标签（显示目标尺寸）
4. 拖动图片调整显示区域
5. 点击"确认裁剪"完成裁剪

#### 视觉设计
- **裁剪框外部**：半透明黑色蒙层（突出裁剪区域）
- **裁剪框边框**：白色实线边框 + 虚线辅助线
- **九宫格线**：淡白色辅助线（帮助构图对齐）
- **四角标记**：主题色装饰角（视觉引导）
- **尺寸标签**：底部显示目标尺寸

### 4. 批量上传
- 支持一次上传最多 6 张图片
- 每张图片独立校验和裁剪
- 已上传图片显示尺寸信息

### 5. 其他功能
- 切换 Tab 时提示清空已上传图片
- 删除图片时二次确认
- 预览图片支持查看原图
- 提交按钮智能判断是否可提交

## 技术实现

### 裁剪计算（核心逻辑）

**1. 裁剪框尺寸计算**
```javascript
if (imageRatio > 1) {
  // 横向图片（宽>高）：以图片高度为基准
  imageDisplayHeight = previewHeight
  imageDisplayWidth = imageDisplayHeight * imageRatio
  
  // 裁剪框高度 = 图片显示高度
  frameHeight = imageDisplayHeight
  // 裁剪框宽度根据目标比例计算
  frameWidth = frameHeight * targetRatio
} else {
  // 纵向图片（高>宽）：以图片宽度为基准
  imageDisplayWidth = screenWidth
  imageDisplayHeight = imageDisplayWidth / imageRatio
  
  // 裁剪框宽度 = 图片显示宽度
  frameWidth = imageDisplayWidth
  // 裁剪框高度根据目标比例计算
  frameHeight = frameWidth / targetRatio
}
```

**2. 裁剪区域计算**
```javascript
// 计算缩放比例
const scale = originalWidth / imageDisplayWidth

// 裁剪框在预览区域中的位置（居中）
const frameX = (screenWidth - frameWidth) / 2
const frameY = (previewHeight - frameHeight) / 2

// 计算裁剪区域相对于原图的位置
const cropX = (frameX - imageX) * scale
const cropY = (frameY - imageY) * scale
const cropWidth = frameWidth * scale
const cropHeight = frameHeight * scale
```

**3. Canvas裁剪实现**
```javascript
const ctx = uni.createCanvasContext('cropCanvas')

// 绘制裁剪后的图片
ctx.drawImage(
  originalUrl,
  cropX, cropY, cropWidth, cropHeight,  // 源图裁剪区域
  0, 0, targetWidth, targetHeight        // 目标画布区域
)

// 导出为临时文件
uni.canvasToTempFilePath({
  canvasId: 'cropCanvas',
  width: targetWidth,
  height: targetHeight,
  fileType: 'jpg',
  quality: 0.9
})
```

### 拖动实现
- 使用 `movable-area` 和 `movable-view` 组件
- 支持全方向拖动（direction="all"）
- 添加阻尼效果（damping="20"）
- 添加摩擦力（friction="2"）

### 裁剪计算
```javascript
// 计算裁剪区域在原图中的位置和尺寸
const scale = originalWidth / imageDisplayWidth
const cropX = -imageX * scale
const cropY = -imageY * scale
const cropWidth = frameWidth * scale
const cropHeight = frameHeight * scale
```

## 使用流程

1. 选择上传类型（手机/平板/头像）
2. 点击上传按钮选择图片
3. 如果尺寸不符，选择"去裁剪"
4. 在裁剪界面中拖动图片调整显示区域
5. 确认裁剪后图片添加到列表
6. 继续上传或点击提交

## 设计亮点

### 1. 原生体验
采用类似手机原生壁纸设置的交互方式，用户无需学习成本，直觉操作。

### 2. 比例锁定
裁剪框比例自动匹配目标尺寸，确保裁剪结果符合要求。

### 3. 视觉引导
- 半透明蒙层突出裁剪区域
- 九宫格辅助线帮助构图
- 四角标记增强视觉识别
- 尺寸标签明确目标

### 4. 流畅交互
- 阻尼和摩擦力让拖动更自然
- 图片自动缩放确保覆盖裁剪框
- 实时反馈拖动位置

## 注意事项

- 切换 Tab 会清空已上传的图片
- 文件大小超限无法裁剪，需重新选择图片
- 裁剪功能已使用 Canvas API 实现真实裁剪
- 裁剪后的图片会保存为临时文件，预览显示裁剪后的效果
- 裁剪框比例根据当前Tab自动调整
- 裁剪框尺寸以图片宽高中较小的一边为基准
- 横向图片以高度为基准，纵向图片以宽度为基准
- 图片会自动缩放以确保能完全覆盖裁剪框
- 裁剪框四个角固定，仅作为视觉标识，不可拖拽
- 裁剪质量设置为 0.9，输出格式为 JPG
