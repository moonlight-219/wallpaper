# 图片裁剪组件使用说明

## 组件概述
`imageCropper.vue` 是一个专门设计的图片裁剪组件，确保裁剪框始终在图片范围内，保持目标比例不变形。

## 核心特性

### 1. 智能裁剪框计算
- 裁剪框根据目标比例和预览区域自动计算尺寸
- 确保裁剪框不超出预览区域边界
- 裁剪框始终居中显示，固定不可移动

### 2. 图片自适应
- 图片自动缩放以覆盖裁剪框
- 图片尺寸为裁剪框的1.2倍，留出拖动空间
- 根据图片和裁剪框的比例智能选择缩放基准

### 3. 拖动交互
- 使用 `movable-area` 和 `movable-view` 实现流畅拖动
- 支持全方向拖动（上下左右）
- 添加阻尼和摩擦力效果，拖动更自然

### 4. 裁剪计算
- 精确计算裁剪区域在原图中的位置
- 自动处理缩放比例转换
- 确保裁剪坐标不为负数

## 组件属性

```javascript
props: {
  imageUrl: String,      // 图片URL
  imageInfo: Object,     // 图片信息 { width, height }
  targetWidth: Number,   // 目标宽度（如1080）
  targetHeight: Number   // 目标高度（如2400）
}
```

## 组件事件

```javascript
emit: {
  close: () => {},       // 关闭裁剪组件
  confirm: (cropInfo) => {}  // 确认裁剪，返回裁剪信息
}
```

## 裁剪信息格式

```javascript
{
  x: Number,      // 裁剪区域左上角X坐标（原图坐标系）
  y: Number,      // 裁剪区域左上角Y坐标（原图坐标系）
  width: Number,  // 裁剪区域宽度（原图尺寸）
  height: Number  // 裁剪区域高度（原图尺寸）
}
```

## 使用示例

```vue
<template>
  <imageCropper
    v-if="showCropModal"
    :imageUrl="cropData.imageUrl"
    :imageInfo="cropData.imageInfo"
    :targetWidth="cropData.targetWidth"
    :targetHeight="cropData.targetHeight"
    @close="closeCropModal"
    @confirm="handleCropConfirm"
  />
</template>

<script setup>
import imageCropper from '@/components/imageCropper.vue'

const showCropModal = ref(false)
const cropData = ref({
  imageUrl: '',
  imageInfo: {},
  targetWidth: 0,
  targetHeight: 0
})

const openCropModal = (path) => {
  uni.getImageInfo({
    src: path,
    success: (info) => {
      cropData.value = {
        imageUrl: path,
        imageInfo: {
          width: info.width,
          height: info.height
        },
        targetWidth: 1080,
        targetHeight: 2400
      }
      showCropModal.value = true
    }
  })
}

const handleCropConfirm = (cropInfo) => {
  // cropInfo: { x, y, width, height }
  // 使用Canvas进行实际裁剪
  const ctx = uni.createCanvasContext('cropCanvas')
  ctx.drawImage(
    cropData.value.imageUrl,
    cropInfo.x, cropInfo.y, cropInfo.width, cropInfo.height,
    0, 0, cropData.value.targetWidth, cropData.value.targetHeight
  )
  ctx.draw(false, () => {
    uni.canvasToTempFilePath({
      canvasId: 'cropCanvas',
      width: cropData.value.targetWidth,
      height: cropData.value.targetHeight,
      success: (res) => {
        // res.tempFilePath 是裁剪后的图片路径
        console.log('裁剪成功:', res.tempFilePath)
      }
    })
  })
}
</script>
```

## 核心算法

### 1. 裁剪框尺寸计算

```javascript
const targetRatio = targetWidth / targetHeight
const previewRatio = previewWidth / previewHeight

if (targetRatio > previewRatio) {
  // 裁剪框更宽，以预览区宽度为基准
  frameWidth = previewWidth * 0.9
  frameHeight = frameWidth / targetRatio
} else {
  // 裁剪框更高，以预览区高度为基准
  frameHeight = previewHeight * 0.9
  frameWidth = frameHeight * targetRatio
}
```

### 2. 图片显示尺寸计算

```javascript
const imageRatio = imageInfo.width / imageInfo.height

if (imageRatio > targetRatio) {
  // 图片更宽，以高度为基准
  imageHeight = frameHeight * 1.2
  imageWidth = imageHeight * imageRatio
} else {
  // 图片更高，以宽度为基准
  imageWidth = frameWidth * 1.2
  imageHeight = imageWidth / imageRatio
}
```

### 3. 裁剪区域计算

```javascript
// 计算缩放比例
const scale = imageInfo.width / imageWidth

// 裁剪框在预览区的位置
const frameLeft = (previewWidth - frameWidth) / 2
const frameTop = (previewHeight - frameHeight) / 2

// 计算裁剪区域相对于原图的位置
const cropX = Math.max(0, (frameLeft - imageX) * scale)
const cropY = Math.max(0, (frameTop - imageY) * scale)
const cropWidth = frameWidth * scale
const cropHeight = frameHeight * scale
```

## 设计优势

### 1. 精确控制
- 裁剪框尺寸精确计算，确保不超出边界
- 图片尺寸自适应，确保能完全覆盖裁剪框
- 裁剪坐标精确转换，确保裁剪结果准确

### 2. 用户体验
- 类似手机原生壁纸设置的交互方式
- 流畅的拖动效果（阻尼+摩擦力）
- 清晰的视觉反馈（蒙层+辅助线+角标）

### 3. 灵活性
- 支持任意目标比例
- 支持任意目标尺寸
- 自动适配不同图片尺寸

## 注意事项

1. 需要在页面中添加隐藏的Canvas元素用于实际裁剪
2. 裁剪后的图片保存为临时文件，需要及时上传或保存
3. 组件使用了 `movable-area` 和 `movable-view`，确保uniapp版本支持
4. 裁剪质量设置为0.9，可根据需要调整
5. 预览区高度为宽度的1.2倍，可根据需要调整

## 兼容性

- 支持 H5、微信小程序、App
- 需要 uniapp 2.0+ 版本
- 需要支持 Canvas API
