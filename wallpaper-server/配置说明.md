## 三种配置方式

### 方式1：使用默认值（最简单）

如果上面的默认值就是你的实际配置，直接运行即可：

```bash
java -jar target/wallpaper-server-0.0.1-SNAPSHOT.jar
```

### 方式2：修改 application.yml（推荐）

直接修改 `src/main/resources/application.yml` 文件中的默认值。

例如，如果你的 MySQL 密码是 `mypassword`，修改：

```yaml
password: ${MYSQL_PASSWORD:mypassword}
```

### 方式3：使用环境变量（生产环境推荐）

#### Linux/Mac 设置环境变量：

```bash
# 临时设置（当前终端有效）
export MYSQL_USERNAME=root
export MYSQL_PASSWORD=your_password
export MYSQL_DATABASE=wallpaper_db

# 然后运行
java -jar target/wallpaper-server-0.0.1-SNAPSHOT.jar
```

#### Windows 设置环境变量：

```cmd
# CMD
set MYSQL_USERNAME=root
set MYSQL_PASSWORD=your_password
java -jar target/wallpaper-server-0.0.1-SNAPSHOT.jar
```

```powershell
# PowerShell
$env:MYSQL_USERNAME="root"
$env:MYSQL_PASSWORD="your_password"
java -jar target/wallpaper-server-0.0.1-SNAPSHOT.jar
```

#### 使用 .env 文件（需要额外配置）

创建 `.env` 文件：
```
MYSQL_USERNAME=root
MYSQL_PASSWORD=your_password
MYSQL_DATABASE=wallpaper_db
```

### 方式4：命令行参数（最灵活）

```bash
java -jar target/wallpaper-server-0.0.1-SNAPSHOT.jar \
  --spring.datasource.username=root \
  --spring.datasource.password=your_password \
  --spring.datasource.url=jdbc:mysql://localhost:3306/wallpaper_db?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
```

## 推荐配置方案

### 开发环境
直接修改 `application.yml` 中的默认值，简单直接。

### 生产环境
1. 保持 `application.yml` 中的默认值为占位符
2. 使用环境变量或命令行参数传入真实配置
3. 敏感信息不要提交到 Git
